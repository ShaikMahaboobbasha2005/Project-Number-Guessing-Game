# 🎯 Number Guessing Game

A simple and fun **Number Guessing Game** built while learning JavaScript from **Colt Steele's Web Developer Bootcamp**.

The player has to guess a randomly generated number within a limited number of attempts.

## 🚀 Features

* 🎲 Generates a random number for every new game
* 🔢 Allows the user to enter a number as a guess
* 📉 Tracks the number of remaining attempts
* 💬 Provides feedback such as:

  * Too High
  * Too Low
  * Correct Guess
* 🏆 Displays a winning message when the correct number is guessed
* 🔄 Option to start a new game

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📚 What I Practiced

Through this project, I practiced:

* DOM Manipulation
* Event Listeners
* Handling User Input
* Conditional Statements
* Random Number Generation
* Updating the UI dynamically
* Game Logic

## 🎮 How to Play

1. Enter a number within the specified range.
2. Click the **Submit Guess** button.
3. You will receive feedback on whether your guess is too high or too low.
4. Keep guessing until you find the correct number or run out of attempts.
5. Start a new game and try again!
